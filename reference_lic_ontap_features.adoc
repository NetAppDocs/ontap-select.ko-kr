= ONTAP 기능에 대한 ONTAP Select 지원
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
ONTAP Select 대부분의 ONTAP 기능을 지원합니다. 대부분의 ONTAP 기능은 클러스터를 배포할 때 각 노드에 자동으로 라이선스가 부여됩니다. 하지만 일부 기능에는 별도의 라이선스가 필요합니다.


NOTE: 하드웨어별 종속 관계가 있는 ONTAP 기능은 일반적으로 ONTAP Select에서 지원되지 않습니다.

== 기본적으로 라이센스가 부여되는 ONTAP 기능

| CIFS를 선택합니다 | link:https://docs.netapp.com/us-en/ontap/smb-admin/index.html["ONTAP SMB"^] |

| 키 관리 상호 운용성 프로토콜(KMIP)을 사용한 외부 키 관리 | link:https://docs.netapp.com/us-en/ontap/encryption-at-rest/configure-netapp-volume-encryption-concept.html["외부 키 관리 활성화 및 구성"^] |

| 플랙스클론 | link:https://docs.netapp.com/us-en/ontap/volumes/flexclone-efficient-copies-concept.html["ONTAP FlexClone 볼륨"^] |  


| iSCSI  a|

| NFS 를 참조하십시오 | link:https://docs.netapp.com/us-en/ontap/nfs-admin/index.html["NFS 프로토콜용 ONTAP 파일 액세스"^] |

| 스토리지 VM 재해 복구(SVM DR) | link:https://docs.netapp.com/us-en/ontap/data-protection/snapmirror-svm-replication-concept.html["ONTAP SnapMirror SVM 복제"^] | ONTAP Select는 SVM DR을 소스 및 대상으로 모두 지원하며 최대 16개의 관계를 설정할 수 있습니다. SVM DR 지원은 소스 ONTAP 버전에서 +2 버전까지만 사용할 수 있도록 제한됩니다. 예를 들어, ONTAP Select 9.16.1 소스는 대상 ONTAP 버전 9.16.1, 9.17.1 또는 9.18.1에 연결할 수 있습니다.

== ONTAP 기능은 별도로 라이센스가 부여됩니다

ONTAP Select에서 지원되지만 기본적으로 라이선스가 부여되지 않는 다음 ONTAP 기능에 대해서는 별도의 라이선스를 취득해야 합니다.

[cols="1,1,1"]
|===
| 기능 | 자세히 알아보기 | 참고 


| FabricPool | link:https://docs.netapp.com/us-en/ontap/concepts/fabricpool-concept.html["ONTAP FabricPool"^] | StorageGRID 활용 시 FabricPool 라이센스가 필요하지 않습니다. 


| MetroCluster SDS | link:https://docs.netapp.com/us-en/ontap/concepts/mcc-sds-ontap-select.html["MetroCluster ONTAP Select용 SDS"^] | 본 상품은 ONTAP Select 프리미엄 라이선스 상품입니다. 


| SnapMirror 클라우드 | link:https://docs.netapp.com/us-en/ontap/concepts/snapmirror-cloud-backups-object-store-concept.html["SnapMirror 클라우드 백업을 오브젝트 스토리지에 저장"^] | link:https://mysupport.netapp.com/site/help["비기술 지원 사례 개설"^]SnapMirror 클라우드 라이센스를 취득해야 합니다. 
|===
